# メテノ：流星フォルムでためてコアで撃つ戦術比較（試験版）

更新日：2026-10-20。開発ブランチ `feature/minior-energy-hold-20261020`。
**試験実装。ユーザー希望により、実機対戦による照合前でも本番アプリで利用可能にする。対戦の正確性・実機のCP/レベル補正は未検証。**

## 仕様
- メテノがHP50%**未満**になった時点で、流星→対応するコアへ変わる。変身時も残HP・最大HP・ゲージエネルギーを維持する。
- 同じシールド・対戦相手で、`instant`（PvPoke標準AI）、`hold`（コアになるまでゲージ技を温存）、`adaptive`（温存しつつ、エネルギー溢れ・被撃破の危険・今の技でKOなら即撃ち）を比較する。
- 戦術別Battle Ratingと採用戦術を全対面について保持する。S0/S1/S2/i0y1/i0y2/i1y2、相手IV4モードは従来どおり。
- 各対面で選べた最高Ratingを既存の完全支配・唯一勝利・S/A候補選定に入力する。この最大値は実戦で先読みできない**上限評価**。画面はその点と未検証を常時表示する。
- 即撃ちでは勝てず温存すると勝てる対面だけ、「ゲージ温存で逆転」として表示。情報過多を避けて例は3件まで。
- メテノ以外はPvPoke標準AI、既存のCSV・コピー・ニックネーム形式を維持する。
- キャッシュには戦術情報が保存されないため、試験版ではメテノに限りSQLite再利用とパーツ再利用を無効化。データ欠損・不整合なら停止、通常Chromiumへ無言で切り替えない。
- 証跡：最新バッチとアーカイブに `minior_strategy_evidence.json` を保存。
- `minior` でもコア単体指定、GameMasterで色・流星/コアの対応が未確定な場合は計算を拒否。別のコア色を勝手に使わない。

## 実戦精度の未検証
登場直後の報告では、GOバトルリーグに入る際のコア→流星で、レベル・CPが単純な同一レベルのフォルムチェンジとは異なる可能性がある。
この試験版は**流星のCP1500までの最適レベル**を使う近似。現物のコアを投入したときの実戦レベルと一致する保証はない。
変身時のダメージ適用順序も独自Hookで模擬しており、ゲーム実機との対照テストが必要。
対戦精度の正式確定までに、将来必要な追加検証：

1. メテノが現行GameMasterの対象フォルムとして登録され、対応コアIDを一意に解決できる。
2. Lv/CP/HPの変換を実機の複数IV・複数リーグで照合する（Lvが変わるならその規則を再現）。
3. 流星で通常技→HP49%相当→コアでゲージ技を撃つ動き、CMP、シールド、エネルギー溢れを実機で検証。
4. 24条件の完走、証跡件数、S/A評価とUIの有無、非メテノの回帰テスト。
5. 本番は試験版として提供し、デプロイ成否と現行機能の健全性を確認する。実機の一致検証は未完了として残す。

**このブランチ単体の静的・単体テスト合格を、本番の対戦精度の証明にしないこと。**
