# Phase 7: 6-3選出と3対3戦術の小規模Monte Carlo学習

## 目的・範囲

第6段階の `SixToThreeEnvironment`（既存PvPoke計算を利用）から、**実際に終了した3対3の結果**だけを用いて、6体から3体＋先発を選ぶ判断と、対戦中の行動価値を少量学習する。

本工程は**学習処理の配線と品質確認用の基線**であり、強いAIの完成、PPO実装、大量自己対戦、メタへの汎化、実機再現を意味しない。モデルは表形式のfirst-visit Monte Carlo（状態・行動別の平均終端報酬）を使う。戦術行動すべてに同じ終端勝敗を帰属させるため、細かな因果的寄与の学習は今後の課題。

## 追加ファイル

- `pvpoke_rl_mc_train.py`：許可された公開観測からのみ状態キーを生成、合法行動内からepsilon-greedyに行動選択、終了試合のみ表を更新。公開状態のハッシュと訪問数・平均報酬だけを保持。
- `tools/run_rl_mc.py`：`tests/fixtures` の**合成6体**と固定GameMasterを使用する短いローカル学習・評価CLI。評価では新しい乱数seedと異なる相手の秘匿選出を使用し、**評価中は学習しない**。
- `tests/test_rl_mc_train.py`：情報隔離、選出・戦術の更新、異常終了での学習除外、行動制限、決定論的選択、チェックポイント検証、実3対3ワーカーとの結合試験。

既存の `Battle.js`、PvPoke GameMaster、厳選アプリの保存データ、クラウド環境、サービス公開APIは変更しない。

## 実行方法

```sh
PYTHONPATH=.:tests python -m unittest test_rl_mc_train
PYTHONPATH=.:tests python tools/run_rl_mc.py --train 8 --evaluate 4 --seed 12
```

モデルをローカルへ保存して再開する場合のみ、明示的にパスを指定する。既存のチェックポイントは上書きしない。

```sh
PYTHONPATH=.:tests python tools/run_rl_mc.py --train 8 --evaluate 4 --save /tmp/rl-mc-001.json
PYTHONPATH=.:tests python tools/run_rl_mc.py --load /tmp/rl-mc-001.json --train 8 --evaluate 4 --save /tmp/rl-mc-002.json
```

1回あたり学習・評価それぞれ0〜32試合の上限。保存はローカル0600権限の新規ファイルのみ。学習途中のプロセス・CI異常終了を勝敗扱いせず、未検証データをモデルへ投入しない。再開時の乱数列は新しいシードで開始されるため、保存された重みの継続であり完全なRNG状態再現ではない。

## 報酬・公平性の境界

- 選出方策に渡すデータは自分の公開可能な編成情報と、相手の公開6体・既知技のみ。相手の実際の選出、IV、隠れた控えは渡さない。
- 戦術方策には第6段階の `observe()` から自分の状態・相手の公開済み種族・HPの区間・公開技・合法行動のみを渡す。
- `private_replay()` はトレーナーから呼び出さない。
- `terminated=True` かつ `training_eligible=True` で、合法な報酬および `selection_reward` が一致する場合だけ更新する。
- `timeout`、`unsupported`、ワーカー異常、未完了の試合は更新しない。
- 対戦本体は相手の秘匿チームを正しく保持するが、**信頼された評価側の入力と方策入力の分離はプロセス境界による強制隔離ではない**。任意の外部提供ポリシーを同一Pythonプロセス内で安全に走らせるものではない。
- 保存表は状態のSHA-256キー・行動・更新回数・平均報酬を持ち、相手の秘匿編成やリプレイ履歴そのものは保存しない。

## 受け入れ条件と未対応

- 単体テストと合成データのネイティブ結合テストを通す。
- CIで学習4試合、評価2試合の小規模実行を実施し、更新件数・完走数・破棄件数を確認する。実際に学習できた件数はログで確認すること。
- 上記CIは**大規模強化学習の性能保証やメタ勝率を意味しない**。評価が改善するとは限らない。
- 次に必要な実装は複数方策・相手の選出分布の多様化、状態表現と報酬設計の改善、強化学習アルゴリズムの比較、独立した評価環境の整備。
- 独立レビューをすべての小変更で反復しない。第6段階レビューで確認したPvPoke計算を再利用し、計算本体が変わらないなら学習境界・報酬・保存だけ追加確認する。
- Draft PRのまま、ユーザー承認なしにマージやデプロイを行わない。ChatGPT接続PvPoke MCPは禁止。
