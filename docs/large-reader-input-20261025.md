# 大量取り込み・読み取りアプリからの直接連携

更新: 2026-10-25 JST。Web正本は jagaimoUK/pokemoniv。

- 1種類・1技構成の上限を150体から4,096通り（0〜15の全個体値）へ統一。
- グループ取り込み、直接入力、24条件処理、IVWorkflowで同じ定数を利用。
- CP違いの出所データは保持。同じ個体値の計算は従来どおりまとめ、複数の進化先にも割り当てる。
- 読み取りアプリのURLフラグメントから受け取る上限をUTF-8で384,000バイトへ拡大。アドレスバーから消して入力欄へ反映。URLのクエリやHTTPリクエストURLには個体値を含めない。
- 取り込み・計算リクエストの容量も拡大。文字数・バイト数を区別して制限し、切り捨てない。
- 受信後は「貼り付けた内容を取り込む」で確認し「計算して推薦を表示」で開始。未接続なら先に従来のログインが必要。自動で対戦計算を開始しない。
- 新規テストで151/500/4096件、CP違いと複数進化先、無効値、重複、日英混在の大きなフラグメントを確認。全4096件で対戦を完走した性能試験ではない。
- Android更新版は jagaimoUK/PokemonIVReader の feature/bulk-reader-transfer-20261025、v1.4.5-preview を参照。

本番反映・CI状態はPRと実際の配備状態で確認する。ソース変更と配備成功を混同しない。
