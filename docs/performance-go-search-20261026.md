## 学習すると実務に役立つ点

1. **計算量**: 同じ最大値を候補数だけ計算し直す処理は、先に一度集計すると候補が多いほど効く。ただし「同点の最高点が残るか」を考え、上位2つを保持する。
2. **責務分離**: 勝敗の評価とゲーム用検索文字列の生成を分ける。文字表記の修正が推薦ロジックに波及しにくくなる。
3. **リファクタリングの証拠**: 一部の見た目だけでなく、旧実装と新実装の出力全体を比較する。500と501、同点、完全に同じ結果など境界を試す。
4. 別の高速化手段には並列化や候補削減もあるが、この変更は重複計算の削減を使う。対戦の精度・対象数を落とさず改善するため。
