# 通常・シャドウの訂正と一括変更（2026-10-18）

Androidは `android-integration/shadow-toggle/Apply-ShadowToggle.ps1` をWindowsの元プロジェクトに適用する。読み取りフロートに通常／シャドウのスイッチを追加し、押した時点のモードを画像の解析に渡す。自動判定は設定から利用可能。履歴の通常・シャドウ変更ボタンを明記し、手動修正の診断表示も保持する。既存の厳選コピーオーバーレイは変更しない。

Webはフォームまたは取り込み済み全種類に対し、通常／シャドウ／リトレーンを一括指定できる。対応するspecies IDを変更して再計算し、コピー・Android共有にもshadow／purified／通常除外条件を反映する。進化前の元個体のspeciesとCPも保持する。これは登録区分の修正であり、IVやCPのリトレーン後の数値への自動変換は行わない。リトレーン済みの数値を入力する。変更後の計算が必要。旧結果は変更しない。

全ジョブと元個体の変更先・技を先に検証し、どれかが対応しない場合は全体を変更しない。変更先で元の技が利用不可なら、検証済みの推奨技を使い画面へ表示する。直前の区分変更を取り消せる。計算中と再開待ちは変更しない。

検証：新規一括変更テスト、共有、連続計算、表示・ニックネーム、Android直接送信テスト成功。Kotlinでスイッチ実装と判定処理をコンパイルし、手動通常指定・シャドウ指定・自動判定のテスト成功。Android差分適用の冪等性を確認。

既存 `test_app_ui_reader_bridge.js` は現在のmainにも存在しないモバイルCSS配置を要求し、変更前・変更後とも失敗する既知の別件。今回の変更ではナビの位置を変更しない。Android全体のビルド、Windows上の適用、実機確認は未実施。更新スクリプトが正式環境でビルドし、失敗時はソースを復元する。
