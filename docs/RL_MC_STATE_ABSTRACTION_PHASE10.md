# 第10工程: 公開戦術状態の集約とv1/v2の対照実験

## 背景と確定した実測

第9工程 `7a7bfae4a0eec0f79b62d3c791332f4983e3676c` では8つのCIが成功した。
CIの小規模合成学習8試合では4試合が正常終了・4試合除外、独立評価の6条件では、旧学習済みモデルの判断842回のうち、学習済み状態に一致したのは6回（0.71%）、その6回はすべて6-3選出状態であった。学習済み行動を選んだ回数は**0回**で、戦術状態の一致は0回だった。学習済みモデルの勝率改善は認められていない。

固定ルールCPUは評価6条件すべてで正常終了できず、勝敗を計算するための有効な分母がなかった。これらは少量の合成編成・固定CPUのみでの測定であり、実大会の統計ではない。

## 実装範囲

- `pvpoke_rl_mc_generalized.py`：**任意選択**の`rl-public-mc-generalized-v2`。学習器自体はv1の第一訪問Monte Carlo平均報酬テーブルを維持。公開観測から抽出する戦術状態キーのみ集約する。
- v2の戦術キーは、自己場の種族と装備技、自己・相手のアクティブHPの大まかな区分、共有シールド、能力変化の符号、相手の公開済み技と種族、控えの生存状態、合法行動を含む。**交代先の選択肢がある場合は、交代先の種族・HP区分を保持**して、`switch_1`の意味が異なる状態を不用意に統合しない。
- 戦術キーから細かいHP値・エネルギー値・クールダウン値を省き、違う試合で同じ特徴の局面に遭遇したとき過去の経験が使われやすいようにする。ただし情報を集約するため不適切な一般化が起きる危険もあり、強さの改善は未検証。
- 6-3選出キーは従来の公開6体の組み合わせを維持する。非公開の相手3体・個体値・未公開技・`private_replay()`をモデル入力に含めない。
- v1とv2は**別スキーマ**。v1チェックポイントをv2として暗黙的に読み込まず、v2をv1としても読み込まない。従来のv1 CLIのデフォルト動作は変更しない。
- `tools/run_rl_mc.py --policy v2`で合成学習とローカル保存が可能。 `tools/evaluate_rl_mc.py --policy v2`で同じ初期条件・同じ学習試合数のv2評価が可能。
- CIは従来v1の学習・評価コマンドを維持し、同じ条件のv2評価を**追加1回だけ**実行する。出力には学習済み状態・選んだ学習済み行動のヒット率、6-3選出の一致、正常終了の件数と除外理由を含む。

## 実行例

```sh
PYTHONPATH=.:tests python -m unittest test_rl_mc_generalized test_rl_mc_evaluation
PYTHONPATH=.:tests python tools/evaluate_rl_mc.py --policy v1 --train 8 --evaluate 6 --seed 12
PYTHONPATH=.:tests python tools/evaluate_rl_mc.py --policy v2 --train 8 --evaluate 6 --seed 12
PYTHONPATH=.:tests python tools/run_rl_mc.py --policy v2 --train 8 --evaluate 4
```

v2を保存する場合のみ `--save` で**存在しない新しいファイル名**を指定する。異なるモデルスキーマ間で重みを移行しない。実際のデータベース・本番API・PvPokeの計算本体には一切書き込まない。

## 受け入れ条件

1. v1・v2が同じ観測契約に従い、非公開データを参照しないこと。
2. v1/v2の保存データは互いに読み込み拒否。既存のv1テストが通ること。
3. HP/エネルギーが近い局面はv2で同じキーになり、シールドや交代先が異なる局面では区別すること。
4. 正しいKO決着だけが学習を更新。タイムアウト・未対応は除外すること。
5. 6試合の合成評価結果から正常終了・除外・再利用率を比較すること。**勝率改善が確認できない場合は改善と宣言しない**。

## 重要な制限

- この検証は小規模で、v2が実戦で強いことは証明しない。戦術学習の分母が少なければ、さらに状態抽象度を変える前に評価サンプルの完走率と相手分布を整える。
- 固定ルールCPUが完走できない場合、途中終了を敗北に変換するなどの便宜的な処理をしない。
- モデル選定・状態集約と、既存のPvPokeエンジンの実機再現性は別に検証する。
- 本番デプロイ・PRマージは禁止。第6段階の独立レビューは完了済みなので対戦エンジンの全面再レビューを繰り返さない。
- ChatGPT接続PvPoke MCPは直接・間接とも使用禁止。
