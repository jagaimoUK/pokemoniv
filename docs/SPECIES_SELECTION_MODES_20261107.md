# ポケモンごとの通常・詳細厳選設定

右上の「設定」から日本語・英語でポケモンを検索し、詳細厳選をONにできます。未設定・OFFは通常厳選（Default × 6条件）、ONは詳細厳選（相手IV 4種類 × 6条件）です。設定は種・姿・シャドウの正確なIDごと、このブラウザに保存します。個体値、CP、メタ、技構成は変更しません。

複数種の入力も、単一種の入力も、開始時に各種のモードを各ジョブへ固定します。技構成を展開したジョブにも継承し、通信再試行・ページ再読込・中断再開で別モードに変わりません。設定を後から変えても実行済み・実行中の計算には適用しません。旧形式の未完了ジョブには、元のバッチのモードを引き継ぎます。新規ジョブは右上設定に従い、未設定なら通常です。

設定一覧は検索と50件ずつの表示でDOM生成を抑えます。ネイティブdialogを使い、モバイルでもフォーカスをダイアログ内に保ち、閉じる・Escapeで戻れます。保存不可の場合は現在画面での一時設定であることを表示します。

保存キーは `pvpoke-app-selection-modes-v1`。秘密情報・認証情報は含みません。既存のブラウザバックアップに追加し、新キーがない旧ファイルもチェックサムを改変せず読み込めます。競合する設定を自動上書きしません。

検証はモード初期値・姿別設定・保存・混在キューの実送信値・再開・移行互換性のテスト、および既存のJS/Python回帰テスト。CIでは既存の実ブラウザテストにモバイル/デスクトップの設定操作と再読込保持を追加しています。ユーザーの認証済みセッションや実際の対戦計算データはテストに使用しません。ChatGPT接続のPvPoke MCPも使用しません。

設計上、画面の選択値を実行途中に毎回読むのではなく、実行開始時の条件をジョブに固定します。これにより、再試行しても同じ要求を再送でき、結果キャッシュと中断再開の条件が揃います。
