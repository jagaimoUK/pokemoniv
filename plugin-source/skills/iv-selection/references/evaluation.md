# 実測評価基準（24条件）

## 原則
S/Aはこの候補集合・相手集合・技構成・シールド条件におけるGPTの推薦分類で、PvPoke公式ランクではない。勝敗推定だけ、平均レートだけ、PvP個体値順位だけでS/Aは決めない。レーティング未取得の条件を実測済みとして扱わない。

## 1. 全条件の完備性
4相手IVモード（default/rank1/attack/defense）×6シールド条件（s0/s1/s2/i0y1/i0y2/i1y2）の24組を確認。簡易指定ならDefault×6条件だけを確認。各候補に同じ相手技構成が存在すること、欠損・無効行・重複行を内部で検証。相手の別技構成は別対面。通常とshadowは別対面。CP・レベルが入力候補の上限内であることを確かめる。欠損候補と完全候補を同じ総合順位で比較しない。

## 2. 重要対面
ユーザーが先頭・裏・苦手対面や重要メタを指定していたら、それらを最優先する。「強い個体」の意味は、先頭のメタポケモンを想定したとき、その裏に来る相手に互角以上で対応できる個体である。指定がなければ、収録メタ87構成のうち結果の差が大きい相手を候補として抽出し、重要度は仮定とする。使用率を知らない場合に高使用率と断言しない。

## 3. 数値比較の順番
- 同一相手、同じ相手個体値モード、同じシールド条件でのみ候補同士のレーティング差をとる。
- レーティング500の境界をまたぐ「対面の勝敗方向の反転」を最優先で抽出する。ちょうど500は互角目安。正式なPvPoke勝敗カウンターがないときは勝敗推定として扱う。
- S0/S1/S2だけでなく不利シールド（i0y1、i0y2、i1y2）の優劣・代替可能性を照合する。
- 平均・中央値・最小rating、500超割合は補足比較として内部利用し、「勝利数推定」を正式な勝数と言わない。
- 相手4モードでの安定性と、特定モードでだけ改善する対面を分ける。
- 全対面・条件のratingで他候補以上、少なくとも1つで上なら支配候補とみなす（完全同値は同等扱い）。重要対面を失うなら平均上昇があっても評価の際に考慮する。

## 4. 推奨の分類
- **S**: 重要対面の独自改善、または重要対面と不利条件を横断する安定性を実測で裏づけられる非支配の第一候補。
- **A**: Sの役割を概ね維持しつつ一部を落とす代替、または限定条件に独自の強みを持つ候補。
- 無理にS/Aを割り当てない。候補数が少ない・重要度未合意・実測欠損なら暫定扱い。推薦の件数に固定上限や最低件数を設けない。
- `candidate_evidence_complete` と `candidate_evidence_count` を確認。全候補 `candidate_evidence` の比較信号（`unique_gt500`、`clear_leads`、不利シールド・重要対面の内訳）で、総合順位が低い専門個体も発掘する。500超は他候補より独自に500を超える**Rating上の推定**、20以上のリードは条件間の同じ相手における数値差。いずれもそのままS/Aにしない。重要対面の根拠を検証する。
- `review_ivs` やハイライトは抜粋。全候補差分はサーバー側で集計されるが、個体別 `examples` は最大3件。`examples_truncated` で必要な事例が省略され、推薦が変わり得るときだけ詳細ツールを追加で読む。全候補の評価を最大12体に制限しない。

## 5. 最終表示の標準形
**通常の最終回答は「おすすめ個体と英語検索式」のみ**。個体別の見出し、独自の強みを示す短い説明、その個体の検索式以外は表示しない。S/Aの根拠は相手名・具体的なシールド・Ratingの差として各個体の説明内に収める。冒頭の挨拶、計算件数、比較表、全条件集計、独立した結論、注意事項、ツール実行報告、所要時間、末尾の問いかけは出さない。ただし実行エラー、欠損、重大な根拠不足は隠さず簡潔に説明する。ユーザーが明示的に追加情報を要求した場合だけ増やす。

**1位｜0/11/12｜S候補｜重要メタ対応型**

アーマーガア（アイアンヘッド型）S1でRating506。他候補の最大430より優秀で、互角の目安500をこの個体だけ上回る。

```text
Quagsire&0attack&3defense&3hp
```

上記は表示例であり、実測していない対戦やランクを流用しない。実際の個体値に応じて英語検索式を作成し、推薦個体1体ごとに独立したコードブロックで表示。区分検索であり完全一致を保証しないが、通常は独立した注意書きを出さない。

## 6. ファイル
通常の成果物はチャット上の推薦個体と検索式。データベース取り込み用CSVはユーザーが明示的に求めた場合のみ生成する。内部分析用CSV/ZIPの保持は可能。
