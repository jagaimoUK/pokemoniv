# PvPoke 個体値厳選 v0.3.4

PvPoke MCPの24条件実測データとProject内メタ構成を使い、重要対面に基づき候補IVを選ぶための個人用プラグイン。

- 自動相手IVは `default` / `rank1` / `attack` / `defense` の4種類のみ。Projectの情報源IVは**手動選択時のみ**。
- 対戦はS0/S1/S2および自分のシールドが少ない3条件。合計24条件。
- Projectのメタ構成（初期87行）をサーバースナップショットと照合して使用。**自動同期ではない**。
- `prepare_24_conditions`、`start_24_conditions`、`get_24_summary` は開発用PvPoke MCP接続において2026-10-13に実戦実行・取得成功。ヌオー12個体×87構成×24条件も実行完了。
- **ChatGPTの厳選プラグイン経由の独立したOAuth／ツール検出状態まで検証済みという意味ではない**。連携状態は使用時に確認する。
- 出力はS/A推薦・重要対面・交換条件・個体別の日本語検索式。検索式のIV区分を0 / 1–5 / 6–10 / 11–14 / 15で正確に変換。
- ユーザーの現行指定に従い、Notion向けCSVは生成しない。内部計算用CSV/ZIPはそのまま利用する。
- エンジンのコードやRailwayの接続設定はこのリリースでは変更していない。

利用時は`個体値厳選`、種名、通常/shadow、必要に応じ技構成とIVリストを指定する。詳細は`skills/iv-selection/SKILL.md`。
