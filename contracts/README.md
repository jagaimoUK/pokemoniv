# 個体値テキスト受け渡し仕様 v1

読み取りアプリと厳選アプリの共通仕様。出力する文面は次の形に統一する。

```text
個体値厳選

# シャドウキバニア シャドウサメハダー
15,11,11
7,11,14
```

- シャドウは各種名の直前に `シャドウ` を置く。区間全体に一括指定しない。
- 通常個体には接頭語を付けない。各フォルムの地域名・性別名等を保持する。
- 見出しの各種類に、その区間の全IVを割り当てる。攻撃,防御,HPの順、0〜15。
- 入力側は既存の `キバニア (シャドウ)`、空白なし・全角括弧も引き続き受け付ける。
- 未知の種類・未対応フォーム・不正IVは、通常個体への置換や部分取り込みで回避しない。
- 技省略の可否は別の検証。推奨技のないキバニアなどに技を推測して補わない。
- 読み取り側の保存名・ランキング照合名は維持し、コピー・共有の直前に表記変換する。

## 両アプリの変更・リリース時

1. 形式を変えるときはこの仕様、`iv-text-v1.tsv`、両アプリのテストを同時に更新する。
2. `contracts/reader/IvSelectionText.kt` はAndroidで実際に使うファイルと同一に保つ。
3. Android側で `python tools/check_selection_contract.py --selection-root /path/to/pokemoniv` を実行する。
4. Androidプロジェクトで `gradlew testDebugUnitTest` を実行し、実機でコピー・共有内容を確認する。
5. 厳選側の `IV text transfer contract` CI はKotlinを実行し、その実出力をPythonへ渡す。通常・旧形式・地域フォーム・不正入力の回帰も確認する。

この自動チェックはテキスト生成と入力解析を検証する。画像認識精度、Android全体のビルド、クリップボード権限、実機操作を検証したものではない。
