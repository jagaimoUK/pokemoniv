# CP連携・コンパクトオーバーレイ更新（2026-10-17）

Android Studioの元の `C:\Users\kuros\AndroidStudioProjects\PokemonIVReader` を更新します。
別プロジェクトは作りません。既存の厳選コピーリスト統合済みプロジェクトが対象です。

1. Android Studioを閉じ、ZIPを `C:\new_folder\code` に保存します。
2. ZIPを展開し、PowerShellで `Apply-CP-CompactOverlay.ps1` を実行します。
3. ソース検証・バックアップ・更新・ビルドを自動実行します。異なるソースは変更前に停止し、ビルド失敗時は変更を戻します。
4. 元のプロジェクトをAndroid Studioで開き、Runで端末へ反映します。アプリのアンインストールは不要です。

読み取り履歴を選んで再度書き出すと `0,11,12 CP717 | ウパー` のようにCPと元の種名も渡ります。
Webの「Androidへ送る」または「オーバーレイ用にコピー」を使うと、見出しが正確な個体値になります。
従来の「検索式とニックネームをすべてコピー」は検索式→名前の2行ペアを維持し、CPも含みます。
古い2行形式には正確な個体値の情報がないため、オーバーレイでは個体値の範囲を表示します。

一覧は右上の小さな領域に表示します。外側タップで折りたたみ、GOを操作できます。
「終了」で厳選ボタンも消えます。厳選ボタンの長押しでも終了できます。
取り込み画面の「画面を閉じる」は画面のみ、「オーバーレイ終了」は厳選ボタンも閉じます。
OCRのIVボタンは独立しています。既存のOCR停止操作で終了してください。
コピー済みの検索式・名前は何度でもコピーできます。履歴は取り込み画面から選べます。

端末上では、外側タップとGOの入力、終了後のボタン消去、既存履歴の復元、OCRの動作を確認してください。
CPは読み取り時点の値です。未読取のCPや計算上の強化後CPは検索条件へ追加しません。
